# Trading App

A Flutter-based trading application developed as part of the Trading App Flutter Assignment.

## Features

- Watchlist
- Live Prices Mimic
- Buy/Sell Ticket
- Holdings

## Tech Stack

- Flutter
- Dart
- BLoC
- Clean Architecture

## Requirements

- Flutter 3.47.1
- Dart 3.13.1
- Android SDK
- VS Code
